## What is Junk Store

Your non-Steam gaming hub for Steam Deck - Epic, GOG, Amazon and itch in Game
Mode. All your non-Steam games in one place. No Desktop Mode. No multiple
launchers. Just gaming.

Junk Store is a single launcher for non-Steam games on Steam Deck. It brings
your game libraries from several stores together into Steam's Game Mode
interface, so you do not have to switch to Desktop Mode or juggle separate
launchers.

## Supported stores

Epic, GOG, Amazon, itch, plus emulator and ROM support.

## What this plugin does

1. Press Install Junk Store Pro.
2. A window opens, downloads the installer from junkstore.xyz, and runs it.
3. When it finishes, Junk Store is installed and ready in your library.

The installer needs an internet connection. It does not run anything in the
background and installs directly on the device.
